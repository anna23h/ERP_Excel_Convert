# 退货入库（天猫 ECMS 退货包裹）

来龙去脉见私有库 `ISSUES.md` 的 `[退货入库] A`。**口径已由用户定死在 `return_intake/return_intake.py` 里，
本流程不改代码、不临场另写脚本。**

目标：**货只点一次**——拆包时同时核对包裹（LP 单号）、产品、件数，并抄下批次和 MHD；
PO 和批次导入表都由脚本从同一张点货表生成，不再打印 Lot_Entry 二次点货。

## 第一步：sheet —— 出汇总表 + 点货表

**先问用户这批从几号开始（汇总号）**，不要自己猜；用户给了就直接跑：

```bash
python -m return_intake.return_intake sheet <VoAbnormalBatchExport*.xlsx …> --start 139
```

- 多份导出一起给：同一 `大包号` 的自动并为一批（例：11-03 的 35 单 + 1 单），批与批按退货申请时间升序编号 139、140 …
- 产出 `output/YYYYMMDD/汇总N.xlsx`（SCP / LP / SKU / PZN / 品名 / 数量，PZN 与 SKU 数字相同留空）+ `点货表_汇总N.xlsx`。
- 终端出现 `⚠ 异常拦截状态是 已打包` → 告诉用户包裹可能还没到仓，点货等实物到了再做。
- 交付：报每批单数 / 件数 / 点货表应收件数，给两个文件路径；告诉用户把点货表交仓库，**在电脑上直接填**（表里第一张「说明」页写了怎么填）。

## 第二步：po —— 仓库填完后，出差异清单 + PO 导入表

```bash
python -m return_intake.return_intake po <点货表_汇总N.xlsx …>
```

- 产出 `差异清单_汇总N.xlsx`（包裹未到 / 少收 / 多收 / 多出产品 / 不可售 / 备注）+ `汇总N_PO导入.xlsx`。
- PO **按实收可售件数**（实收 − 不可售）建：供应商、`汇总N   M单ECMS退货包裹YYYY年MM月DD日`、单价 0、税、套件换基础品都照以往退货 PO。
- 交付：原样报终端的合计行（包裹到几个、应收 / 实收 / 不可售 / 入库），**把差异清单里每一行念给用户**（要去跟天猫交涉的就是这些），给两个文件路径。
- 告诉用户在 Odoo：采购 → 导入记录 → 上传 PO 导入表 → 测试 → 导入 → 确认 PO；然后在 Inventory → Transfers 用入库批次录入那张**导出模板**导出这张入库单（WH/IN），交回来。

## 第三步：lot —— 入库单导出 + 点货表 → 批次导入表

```bash
python -m return_intake.return_intake lot <stock.picking 导出.xlsx> <点货表_汇总N.xlsx …>
```

- 产出 `Lot_Import_<时间>.xlsx` + `Lot_Check_<时间>.xlsx`，格式与 `lot_entry` 完全一样（同一套校验）。
- 同一产品同一批次跨包合并；包装上没批次的产品只按数量收货（核对清单里是 NO LOT）。
- 交付：报 ERROR / WARN / 无批次的产品，告诉用户把 Lot_Import 导入那张入库单，再验收。

## 退出码 2（不出任何文件）就停下，原样交给用户

| 终端说 | 意思 | 怎么跟用户说 |
|---|---|---|
| `Odoo 里已有 … 汇总N 的采购单` | 起始号已被占用（sheet）/ 这批已建过 PO（po） | 问是不是号给错了、或已经导入过 |
| `找不到 VO_TOF_ / GW_TOF_ 销售单`、`≠ 导出商品数量` | 退货单和 Odoo 订单对不上 | 报出 SCP / LP，请人工查 |
| `多组件套件`、`已归档`、`不是库存产品`、`进项税不是…` | 产品主数据不符合退货 PO 的写法 | 报出 SKU，请在 Odoo 修主数据后重跑 |
| `点货表有下面这些问题` | 仓库填表有误（没选到 / 未到、不可售比实收多、MHD 过期或认不出、多出产品的 PZN 找不到…） | 把每一行（文件名 + 行号 + 说明）交给用户，改好表重跑 |
| `入库单和点货表对不上` | 导出的不是这批 PO 的入库单，或 PO 在 Odoo 被改过 | 列出对不上的产品，请用户确认导出的是哪张 WH/IN |

## 禁止项

- 不替用户定汇总号；不跳过护栏、不手改产出表让它「过」。
- 不在点货表以外的地方补数据（比如自己猜多出产品的 SKU）——让仓库填 PZN，脚本去 Odoo 找。
- 不连 Odoo 写任何东西：PO 和批次都是用户在 Odoo 里导入。
- 退回来的过期货：脚本会报 MHD 已过期——让仓库把它记成不可售，不要放宽检查。
