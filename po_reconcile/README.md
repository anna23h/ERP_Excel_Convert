# po_reconcile — 采购 quotation ↔ invoice 对账

**状态：未实现**（2026-08-01 建目录占位，随「按流水线拆目录」重构一并落盘）

## 要解决的问题

采购在 Purchase Quotation 里列出向某供应商订购的商品与数量，据此下单。
但供应商很少能一次足量供货——**一张 quotation 的商品常横跨 2~3 次送货**才补齐。

现状：每次到货仓库清点后报给财务，财务按**实收**开一张新 Invoice。
于是原始 quotation 里的数量完全对不上了。理论上该由财务或采购手工把已收部分从 quotation 里扣掉、
只留未到货的，但仓库/采购/财务谁都可能不能第一时间处理，实际执行不下去。

## 打算做什么

脚本吃「原始 quotation 导出 + 该 quotation 相关的全部 invoice 导出」，自动扣减实收数量，
产出一份**更新后的 quotation**（只剩未到货的商品及数量）。

## 已定下的架构口径

- **无状态**：每次把 quotation + 相关 invoice 一起喂给脚本重算差额，脚本自己不记忆任何东西。
- **不做 ERP API 直写**（2026-08-01）。产出「更新后的 quotation 导入表」，由人上传 ERP——
  与现有 `回传ERP销售上传表{店}.xlsx` 同一模式，保留人工过目环节，出错能中断。
  沿用 SPEC 里「第二档 Odoo API 暂不自动化」的判断。
