# 采购 / 成本

## ✅🔑 采购价格收集表 —— 算某几张销售单的采购成本

- **什么时候用**：要核算一张（或几张）销售单的采购成本，需要看这些产品近期**每一笔**实际进价。
- **干什么**：一个产品一行，把它近 N 个月的每笔采购摊在这一行上。**只收集不计算**——
  「成本」列脚本一个字都不写，留空由人填（要跨价分摊就照实写 `70*4.63` 换行 `74*4.68`）。
  不出加权均价（均价是结论不是事实）。
- **产出**：`output/YYYYMMDD/采购价格-<单号+单号>-YYYYMMDD.xlsx`，单 sheet，17 列分四段
  （销售侧 / 成本[留空] / 采购汇总 / 逐笔明细）。
- **怎么启动**：

  ```bash
  python3 -m procure.po_price S04072 S04073 --months 12
  ```

  `--months` 是**采购历史回溯月数**，默认 3。**慢销品 3 个月不够**——
  若某产品「销售数量 > 采购总量」就是窗口太短的信号，加长重跑。
  多张单号写在一起 = 按产品跨单合计（同一客户的不同法人实体就该合起来问）。
- 有 skill：`.claude/skills/采购成本核算/SKILL.md`（Claude 会先问你窗口取多久）。

## 🚧🔑 采购缺口 + 报价比较 —— 还缺多少货、找谁买、什么价

- **什么时候用**：销售单进来了，要决定**还得采购多少、向哪几家询价**。（与上面那张分工：
  这张管决策前，那张管核算时。）
- **干什么**：每产品算缺口 × 曾在哪几家买过 → 产品 × 供应商的报价比较表。
  询价/分配/已下单量**手填，重跑不冲掉**（会回收上一版手填内容）。
- **产出**：`output/YYYYMMDD/采购缺口-<单号+单号>-<时间戳>.xlsx`
  + 英文只读快照 `Procurement-Gap-<单号+单号>-<时间戳>.xlsx`。
- **怎么启动**：

  ```bash
  python3 -m procure.gap_report S04018 S04029
  python3 -m procure.gap_report S04018 --months 6 --fresh   # 不回收手填，从零生成
  python3 -m procure.gap_report S04018 --no-en              # 不出英文版
  ```

## ✅ 采购数量与频次 —— 供应商会议前整理

- **什么时候用**：要和某供应商开会，想看清在他家买过哪些产品、各买了几次多少量。
- **干什么**：纯整理，**不下结论**（不算卖穿率、不做价格趋势）。每产品的采购次数 + 数量，
  外加逐笔明细。
- **产出**：`output/<Vendor>_Purchase_Quantity_and_Frequency.xlsx`
- **怎么启动**（吃 ERP 导出的 xlsx，不连 Odoo）：

  ```bash
  python3 po_frequency/po_frequency.py <purchase.order.xlsx>
  python3 po_frequency/po_frequency.py <purchase.order.xlsx> --vendor PHOENIX
  ```

  导出时已经只筛了一个供应商就不用 `--vendor`。

## ⏳ 采购对账 —— 算「还有什么没到货」

- **什么时候用**：采购在一张 PO 记订购需求，财务按每批实收另建 PO，
  于是采购单永远显示原始订购量、看不出还缺什么。
- **干什么**：比对两边算未到货量，并可回写采购 PO。
  **若出现「财务单已收 > 订购量」说明前提被破，脚本拒绝生成回写表并以退出码 2 中止**
  ——此时回写只会把错误写进 ERP。
- **产出**（默认 `output/YYYYMMDD/`）：`采购对账表-<tag>.xlsx`、`回写导入表-<tag>.xlsx`、
  原始订购量归档 `原始订购量归档-<tag>.xlsx`（落 `results/`）。
- **怎么启动**：

  ```bash
  python3 po_reconcile/po_reconcile.py <purchase.order.xlsx> --buyer P11382
  python3 po_reconcile/po_reconcile.py <purchase.order.xlsx> --buyer P11382 --no-writeback
  ```

  `--finance` 不给则读 Source Document 自动关联。**⏳ 待真实干净数据验证。**

# 销售 / 库存 / ERP 回写

> 这三条都有图形界面，**个人月频维护用**：双击 `ERP回写-Mac.command`，
> 三个页签「销售分析 / 安全库存直写 / FS 回写」。刻意不进给同事用的 VOTool，
> 同事没有入口就不会误触回写。只在 Mac 上跑源码，不打包 exe。下面是命令行等价跑法。

## ✅ 销售分析 + 安全库存提醒 + 回写表

- **什么时候用**：月频维护，看销量排名、哪些该补货、要不要调安全库存。
- **产出**（`output/YYYYMMDD/`）：`销量排名.xlsx`、`补货提醒.xlsx`、`安全库存回写表.xlsx`、
  `安全库存候选值.xlsx`。
- **怎么启动**：

  ```bash
  python3 sales_insight/sales_insight.py <销售数据.xlsx> --products <product.product.xlsx>
  python3 sales_insight/sales_insight.py <销售数据.xlsx> --products <p.xlsx> --safety <安全库存表.xlsx>
  python3 sales_insight/sales_insight.py <销售数据.xlsx> --products <p.xlsx> --test-sku <SKU>
  ```

  `--weeks` 只在旧的整期累计导出上必须给（按周分组的导出会自己数表头）。
  `--cover-weeks` 安全库存按几周量算，默认 2。
  **首次导入 ERP 前先用 `--test-sku` 试水**：只产一个 SKU 的回写表 + 导入前全字段快照供比对。

## ✅ 安全库存直写 —— 不要销售数据

- **什么时候用**：运营直接发来一张安全库存表，只想把值写进 ERP，**不做分析**。
- **产出**（`output/YYYYMMDD/`）：`安全库存回写表.xlsx`、`回写核对表.xlsx`、`未匹配SKU.xlsx`。
- **怎么启动**：

  ```bash
  python3 sales_insight/safety_writeback.py <安全库存表.xlsx> --products <product.product.xlsx>
  python3 sales_insight/safety_writeback.py <安全库存表.xlsx> --products <p.xlsx> --col 15天安全库存
  ```

  `--products` 导出时筛选只勾 `can be sold`，**须含 External ID**。
  `--col` 不给则自动认含「安全库存」的列，命中多个会报错。
  **值为 0 的行默认拒绝**（那等于清零），确实要清零才加 `--allow-zero`。

## ✅ FS 回写 —— 供应商代号写回产品主数据

- **什么时候用**：月频，把采购单里的供应商画像写回 `product.product` 的 `FS` 字段。
- **产出**：`FS回写导入 <日期><tag>.xlsx`
- **怎么启动**（**位置参数，没有 argparse，顺序不能错**）：

  ```bash
  python3 vo_orders/fs_writeback.py <purchase.order.xlsx> <product.product.xlsx> [输出目录]
  ```

## ⏳🔑 库存周报 —— Odoo 直连拉数，销量 × 在手 × 安全库存

- **什么时候用**：周频（已配 launchd 自动跑）。要一张三合一的库存健康表。
- **先跑环境探针**（只读、不产文件）：`python3 odoo_api/discover.py`
- **产出**（`output/YYYYMMDD/`）：`库存周报.xlsx` / `库存周报.csv`、
  `安全库存不一致.csv`、`安全库存待配清单.csv`、`缺货违规风险清单.csv`（给了 `--violations` 才有）。
- **怎么启动**：

  ```bash
  python3 odoo_api/stock_report.py                              # 近 12 周，全渠道
  python3 odoo_api/stock_report.py --ref-contains VO,GW         # 只看天猫 C 端
  python3 odoo_api/stock_report.py --weeks 4 --csv-only         # cron 用
  ```

- **⚠ 渠道口径必须显式给，这是最容易错且错了不报错的地方。**
  销量默认全渠道，但安全库存是给天猫 C 端维护的。同一窗口下「销量前 50 名里配了安全库存的」，
  全渠道算出来 3 个、C 端口径（`--ref-contains VO,GW`）算出来 **45 个**——
  口径混用会把人引向完全相反的结论。launchd plist 默认带 `--ref-contains VO,GW`。
- **⚠ `sale.report` 是实时视图不是快照**，同一历史窗口过些天再拉数字会变。
  **周报不可事后复现，要留证据就留产出文件。**
- `--weeks` **别为了省事调回 4**（默认 12 ≈ 一个季度，4 周是另一个口径的历史遗留）。
  `--exclude-vendor` 默认读 `config.py` 的 `ODOO_EXCLUDE_VENDORS`，用于剔除永不到货的技术性采购单。
  **⏳ 待真实 ERP 连通验证。**

# 出货 / 仓库现场

## ✅ 出口箱单（B2B）

- **什么时候用**：B2B 出货，要给仓库一张 Packing List 半成品。
- **干什么**：机器可知的列（品名/SKU/条码/HS/原产国）填好，
  仓库现场才知道的列（批次/效期/箱号）留空行给人手写。
- **产出**：`output/<SO标识>箱单<日.月>.xlsx`
- **怎么启动**（也可走 VO 拉单 GUI 的「箱单」页签）：

  ```bash
  python3 packing_list/packing_list.py <sale.order.xlsx>
  python3 packing_list/packing_list.py <sale.order.xlsx> --spare 4   # 每 SKU 留 4 行空行
  ```

## ✅ 订货辅助 —— 需求清单 × 采购单 → 订货决策表

- **什么时候用**：要决定补什么货、补多少。**英文界面，给不读中文的同事用。**
- **怎么启动**：双击 `Reorder-Mac.command`（Windows：`Reorder-Windows.bat`），
  选两个文件点 Generate：① 需求清单（完整出货明细表，或一列纯 PZN）② `purchase.order` 导出。
- **产出**：`reorder-YYYYMMDD.xlsx`，一产品一行、英文列名。
- 详见 [订货辅助输入说明.md](订货辅助输入说明.md)。

## ✅ 京东装箱复核瘦身表

- **什么时候用**：京东后台「装箱复核历史查询」导出 45 列，仓库现场只看 5 列 + 序号，要打印给人核对。
- **干什么**：不新建工作簿，在原文件副本上删列 + 插列；同单合并、A4 横向压一页。
- **产出**：原名加 `new` —— `xxx_0.xlsx` → `xxx_0new.xlsx`（`xxx_0(1).xlsx` → `xxx_0new(1).xlsx`）。
  命令行不传输出目录就**就地放在原文件旁边**。
- **怎么启动**（日常走 VO 拉单 GUI 的「京东复核」页签，可多选一次全转）：

  ```bash
  python3 vo_orders/jd_packing_review.py "装箱复核历史查询….xlsx"   # 单份
  python3 vo_orders/jd_packing_review.py ~/Downloads/京东装箱复核    # 整个目录
  ```

  已转过的 `…new…` 文件自动跳过，全选时不用挑。

## ✅ 储位标签 PDF

- **什么时候用**：仓库要贴新储位标签。
- **干什么**：每码一页，QR + 人眼可读文字。**尺寸驱动、按打印机 dot 对齐**
  （几何尺寸先换算成 dot 向下取整再换回 mm，否则热敏点阵会糊）。
- **产出**：`output/labels/储位标签_QR.pdf`（`--png` 另出每码一张 png）。
- **怎么启动**（依赖单独装：`pip install -r requirements-labels.txt`）：

  ```bash
  python3 make_labels.py 储位编码.csv
  python3 make_labels.py 储位.xlsx -c 储位编码
  python3 make_labels.py 储位.xlsx --width 40 --height 20 --dpi 203 --verify
  ```

## ✅ 运单扫码回流（零依赖 HTML）

- **什么时候用**：VO 拉单阶段一↔阶段二之间，**替代纸质勾选 + 手工转录**。可选段，不是独立流水线。
- **怎么启动**：浏览器直接打开 `扫码/扫码回流.html`（跑在仓库机，零依赖、不装东西）。
- 详见 [扫码/README.md](../扫码/README.md)。
