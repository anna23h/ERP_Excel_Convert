# sales_insight — 销售分析 + 安全库存提醒

**状态：未实现**（2026-08-01 建目录占位，随「按流水线拆目录」重构一并落盘）

## 打算做什么

1. 吃 ERP 导出的一段时间（近半年）销售数据，按销量排名。
2. 与另一份 ERP 产品数据交叉比对。
3. 统计热销品的**订购频率**与**每次订购数量**。
4. 库存低于安全库存时提醒下一轮采购。

## 已定下的架构口径

- **状态用明文 Excel，不上 SQLite**（2026-08-01 用户拍板）。这是本仓库第一条**有状态**的流水线——
  安全库存阈值、采购历史需要跨时间记住。选明文的理由：走 Syncthing 在两台 Mac 间同步，
  出问题能直接打开看；SQLite 是不可见状态，多机同步冲突了察觉不到。等数据量真撑不住再换。
- 销售历史每次重新从 ERP 导出算，**不缓存**；只有「安全库存阈值」这类人工维护的数据落盘。
